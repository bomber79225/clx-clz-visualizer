# CLX／CLZ 癌症保障可視化工具 v1.0

一個**與 `haahabcalculater` 完全獨立**的靜態前端專案，延續原有「左側輸入與訊息編輯、右側即時圖卡與複製」工作流程。

## 功能
- 女 CLX／男 CLZ；姓名、民國6/7碼或西元8碼生日、10／20年繳
- 固定以100萬元保額試算，不需客戶自行換算
- 使用 2026-08-24 CLX 真馨相守、CLZ 豪愛無憂**建議書內 P_DATA 工作表之費率**，100萬元 = 100 單位「每萬保費」
- 10年繳：保險年齡18–60；20年繳：18–50；未滿18足歲不可試算
- 自動計算年繳標準保費及預計總繳（不計折扣）
- 圖卡、文案編輯與變數帶入，複製圖片、下載PNG、複製文案
- 資料不送伺服器，前端本機處理

## 啟動
下載所有檔案到同一資料夾，以靜態伺服器啟動，例如：

```bash
python -m http.server 8080
```

在瀏覽器開啟 `http://localhost:8080`。請勿直接以 `file://` 開啟，因為 `rates.json` 使用 fetch 載入。

圖片複製依賴 `html2canvas` CDN 及瀏覽器剪貼簿權限；若無法複製，會改成下載 PNG。

## 保費來源與校驗
來源 Excel 版本：CLX V1.2-1150824、CLZ V1.1-1150824。程式中的標準年繳保費**未計健康管理、轉帳、信用卡等折扣**。
- CLX 女性，30歲，20年繳：每萬費率290；100萬元年繳29,000元、總繳580,000元。
- CLZ 男性，30歲，20年繳：每萬費率296；100萬元年繳29,600元、總繳592,000元。

**重要：**這是業務溝通用摘要，非公司正式DM或核保承諾。癌症等待期間90日，疾病等待期間30日；第1保單年度另有癌症給付規定；無解約金。身故或滿期依條款扣除應申領之保險金。產品資訊、承保條件及投保結果依公司當期正式文件為準。
